# homebrew-tap

A collection of homebrew packages.

## Available packages

- ksd (Cask)

## Usage

```
brew install --cask mfuentesg/tap/ksd
```

> **Note:** `ksd` is migrating from a Homebrew Formula to a Homebrew Cask
> (GoReleaser deprecated the `brews` config key in favor of `homebrew_casks`).
> This file is generated by GoReleaser on each `ksd` release — do not edit
> `ksd.rb`/`Casks/ksd.rb` directly. Until the next `ksd` release is tagged,
> the existing Formula (`brew install mfuentesg/tap/ksd`, no `--cask`) is
> still what actually gets installed.
