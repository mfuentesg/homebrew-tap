# homebrew-tap

A collection of homebrew packages.

## Available packages

- ksd (Cask)

## Usage

```
brew install --cask mfuentesg/tap/ksd
```

> **Note:** `ksd` migrated from a Homebrew Formula to a Homebrew Cask
> (GoReleaser deprecated the `brews` config key in favor of `homebrew_casks`).
> `Casks/ksd.rb` is generated by GoReleaser on each `ksd` release — do not
> edit it directly.
